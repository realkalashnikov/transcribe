# Política de Segurança (Security Policy)

## Versões Suportadas

Atualmente, apenas a versão mais recente na branch `main` recebe atualizações de segurança.

## Reportando Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança no Transcriber:

1. **Por favor, não abra uma issue pública.**
2. Envie um e-mail diretamente para: `rafaeldasilvadeveloper@gmail.com`.
3. Inclua o máximo de detalhes possível, incluindo passos para reproduzir o problema e um possível fix (se disponível).

Agradecemos por ajudar a manter o projeto seguro para todos!
